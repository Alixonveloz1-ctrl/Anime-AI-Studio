# Cómo trabajar en este repositorio

## Al terminar cualquier cambio, da SIEMPRE el enlace de Cloud Shell

El dueño actualiza el estudio desde el móvil. Cada conversación nueva empieza
con Cloud Shell cerrado, y él no busca el repositorio a mano. Así que **todo
mensaje que anuncie un cambio listo termina con este enlace y los dos
comandos**, sin que haga falta pedirlo:

[Abrir Cloud Shell](https://shell.cloud.google.com/?authuser=4&cloudshell_git_repo=https://github.com/Alixonveloz1-ctrl/Anime-AI-Studio&cloudshell_git_branch=main&cloudshell_workspace=.)

```
git pull
./c
```

El enlace clona el repositorio solo, así que sirve igual si Cloud Shell está
vacío. `authuser=4` es su cuenta de Google: sin ese número Cloud Shell abre
otra cuenta y la instalación no aparece.

## Trabaja en `main`

Él trabaja sobre `main` y lo pidió expresamente. No dejes el trabajo en una
rama aparte.

## Escribe en español llano

Nada de nombres de archivo, rutas, ni palabras en inglés en las respuestas:
qué arreglaste, qué está hecho, qué tiene que hacer él. Corto.
